# aegis-edge

AegisEdge is a programmable edge node data plane built using XDP, eBPF, and tc, designed to process and control network traffic at the earliest possible point in the Linux networking stack.

It provides a foundation for building high-performance edge systems capable of filtering, routing, and shaping traffic before it reaches user-space services such as NGINX or Varnish.

It is not intended to be a production-ready system. Instead, it is designed as a minimal, transparent foundation for understanding and experimenting with edge data plane concepts.
